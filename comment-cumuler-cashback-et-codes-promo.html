Comment cumuler cashback et code promo sans perdre l'un des deux ?

Un code promo peut doubler l'économie d'une commande, ou faire disparaître ton cashback. Tout dépend de son origine. Voici la règle à connaître, l'ordre des étapes et des exemples chiffrés.

La règle à connaître

Pour un marchand, un code promo est souvent associé à un partenaire qui l'a diffusé. Si tu utilises un code distribué par un site de bons plans, le marchand peut considérer que c'est ce site qui t'a amené, et pas ton site de cashback. Résultat : le cashback est refusé.

D'où la règle : un code promo est cumulable avec le cashback quand il est autorisé par la fiche du marchand sur ton site de cashback. Les codes affichés directement sur cette fiche le sont en principe ; les codes trouvés ailleurs, pas toujours.

L'ordre des étapes

  1. Ouvre la fiche du marchand sur ton site de cashback et lis la ligne sur les codes promo.
  2. Relève le code proposé sur la fiche, ou vérifie que le tien est autorisé.
  3. Active le cashback, puis remplis ton panier.
  4. Saisis le code au moment du paiement, sans quitter la boutique pour aller en chercher un autre.
  5. Paie et garde la confirmation.

Si tu dois chercher un code, fais-le avant d'activer le cashback, jamais après : aller sur un site de codes entre l'activation et le paiement peut remplacer le suivi.

FAQ cumul cashback et codes promo

Un code promo annule-t-il toujours le cashback ?

Non. Les codes autorisés par la fiche du marchand sont cumulables. Ce sont surtout les codes diffusés par des sites tiers qui peuvent annuler le cashback chez certains marchands.

Où trouver des codes compatibles avec le cashback ?

Sur la fiche du marchand de ton site de cashback. eBuyClub, en particulier, met en avant les codes compatibles.

Le cashback est-il calculé sur le prix avant ou après le code ?

Après : il porte sur le montant réellement payé, généralement hors frais de livraison.

Que faire si mon cashback est refusé à cause d'un code ?

Si le code était affiché sur la fiche de ton site de cashback, fais une réclamation avec ta confirmation de commande. S'il venait d'un site tiers, le refus est probablement conforme aux conditions.

Peut-on cumuler code promo, cashback et carte cadeau ?

Parfois, selon les conditions du marchand et du site de cashback. La part payée en carte cadeau peut être exclue du calcul du cashback.

En résumé

Le cumul fonctionne quand le code est autorisé par la fiche du marchand. Relève le code avant d'activer le cashback, active-le en dernier, saisis le code au paiement et ne quitte pas la boutique. En cas de doute, compare le montant du code au cashback attendu. Les autres pièges sont dans les erreurs à éviter.
